Разработка веб-приложения для проведения опросов студентов

СОСТАВ
PHP-приложение без Composer и сторонних серверных библиотек.
database.sql — таблицы и демонстрационные данные.
css/bootstrap.min.css — локальная копия Bootstrap 5.3.3 (MIT).
config.php — параметры подключения.
records.php — получение основного списка; полный листинг включён в записку.

ЗАПУСК
1. Требуются PHP 8.1 или новее (pdo_mysql, mbstring) и MySQL 8.0.16 или новее.
2. В OpenServer включите PHP и MySQL. Корень локального сайта направьте на эту папку.
   В версиях OpenServer с каталогом domains поместите туда папку проекта.
   Путь и адрес MySQL зависят от конфигурации OpenServer: укажите их в config.php.
3. Импортируйте database.sql в phpMyAdmin. Скрипт создаёт базу student_surveys.
   Импорт рассчитан на чистую базу; повторный импорт в заполненную базу не выполняйте.
4. Измените в config.php host, port, user и password на параметры локальной СУБД.
5. Откройте login.php через адрес локального сайта, а не двойным щелчком по файлу.
6. Альтернативный запуск: из папки проекта выполните php -S 127.0.0.1:8000,
   затем откройте http://127.0.0.1:8000/ . СУБД должна быть запущена отдельно.

ДЕМОНСТРАЦИОННЫЙ ВХОД
Администратор: admin / Study2026!

Новый хеш можно получить командой php hash.php "НовыйПароль" и записать в password_hash.

ПОРЯДОК ПОКАЗА
Войти администратором; показать список; создать запись; изменить её; открыть
подтверждение удаления; удалить запись; показать справочники или вопросы и итоги.
Выйти и войти под второй ролью, чтобы продемонстрировать ограничения доступа.

ГРАНИЦЫ ВЕРСИИ
Приложение рассчитано на администратора опросов и студентов. В базовом варианте используются вопросы с единой шкалой от 1 до 5. Прохождение связано с учётной записью и не является анонимным; в итогах показываются агрегированные значения без списка индивидуальных оценок.
В дальнейшем можно добавить разные типы вопросов, выбор учебных групп и выгрузку итогов. Анонимный режим потребует отдельной схемы выдачи одноразовых приглашений и не должен обозначаться как свойство текущей версии.
